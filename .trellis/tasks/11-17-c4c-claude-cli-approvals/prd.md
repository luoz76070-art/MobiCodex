# C4c 手机交互

在 C4b 上实现 Claude CLI 工具审批、提问、权限模式和模型切换。工具审批不自动批准；允许一次、原样回传本地设置建议、带理由拒绝。提问支持单选、多选、其他文字及纯文本 preview。等待最多三十分钟，超时拒绝并中断；取消、结束、中断、退出撤回卡片；重复答复明确返回已处理。仅已有 Query 可切 default/plan/acceptEdits 和 supportedModels 中的模型。

验收：注入 SDK 与假 Query，覆盖全部用户场景、生命周期和共享手机界面；七项指定命令通过；指定功能分支提交推送并创建 PR。不运行真实模型，不改变插件 Claude 通道。
