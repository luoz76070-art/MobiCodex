# 机制与边界

F1 在手机发送任务后请求通知权限并启动 AttentionService；App 回前台发现仍有任务时也可启动。服务只有一个工作线程连接 attention SSE，接收 snapshot/item/ping，1–30 秒退避重连；无任务后按原空闲宽限退出，断连十分钟退出。通知由 AttentionNotifications 统一发布；点击通过 AttentionPlugin 保留的 open 事件回到网页。401/403 原本停止服务，网页连接层显示重新配对。

在同一服务 sync/idleCheck 中增加十秒状态检查，不增加网络请求。纯 Java GatewayOfflineState 使用单调时钟计算两分钟，墙上时钟仅记最后一次成功时间；SSE 200、有效事件和心跳代表成功。系统无可用网络时清计时并静默显示；已提醒的锁存只在网关恢复、服务停止或切换连接时重置，避免开关或手机断网造成重复提醒。系统 VALIDATED 网络或仍工作的本地 SSE 可证明手机有路由，不探测公共地址。

恢复选择直接 cancel：故障已经消失，无需另发恢复通知。关闭开关、停服务、切换凭证也撤掉旧提醒；generation 丢弃旧连接的迟到成功和认证错误。重复 start 不重置连续离线时间。

原生与网页配置增加 offline 字段，旧偏好缺字段默认开启；只选离线提醒也复用原服务的任务启动/空闲退出。使用既有通知 open 事件的 gateway 键打开全局设置，无会话路由或额外网络依赖。
