# 实施与自审

1. 提取原生纯 Java 离线状态机，接入 F1 服务、系统网络状态及共享通知发布。
2. 配置桥接、网页偏好和全局通知开关同步增加 offline；通知点击打开连接设置。
3. 按现有 javac/main 原生测试方式验证真实 Java 类；网页测试覆盖默认值、旧设置迁移、开关、桥接配置与冷/热点击。
4. 全量手机测试、类型检查、lint、构建和 Android assembleDebug；记录真实编译限制和模拟器待验项。
5. 自审范围及隐私，指定分支提交、推送并创建 PR。
