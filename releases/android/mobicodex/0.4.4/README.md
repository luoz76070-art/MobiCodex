# MobiCodex 0.4.4（versionCode 47）

2026-11-19 · Android 6.0+ · 包名 `com.mobilecodex.app`

## 这一版

- **版本号显示正确了**（#51）：「应用更新」和设置里一直显示 v0.4.0（从 0.4.1 起没跟着改），现在显示实际版本。反馈里附带的版本号、界面更新判断兼容性用的版本号也一起改对了。版本号改为构建时从安装包配置读取，不会再对不上。

0.4.2、0.4.3 的改动见 [0.4.2 版本说明](../0.4.2/README.md)和 [0.4.3 版本说明](../0.4.3/README.md)。完整列表见[更新说明](../../../../CHANGELOG.md)。

**电脑端**：这一版不用动。从 0.4.1 或更早升级并且用 Claude CLI 的话，按 0.4.2 的说明重新构建网关。

## 安装

1. 用下载页的安装包覆盖安装 0.4.3 或更早的版本（同一签名，数据保留）。
2. 从 0.4.1 或更早升级并且用 Claude CLI：按[网关管理](../../../../plugins/mobile-codex/README.md)用本版源码构建网关（`corepack pnpm build:plugin`），沿用原配置和工作目录切换到新程序。
