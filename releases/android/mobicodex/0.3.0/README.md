# MobiCodex 0.3.0（versionCode 41）

2026-11-15 · Android 6.0+ · 包名 `com.mobilecodex.app`

## 这一版

- **通知**：手机上发出的任务完成、失败或中断时发系统通知；Agent 等你审批或回答时也会通知，点通知直接进对应线程。
  - 审批通知上可以直接点「允许一次」或「拒绝」。危险命令、权限变更和提问只能打开 App 处理。锁屏上只显示「有任务需要你查看」。
  - 只在有任务运行或有待处理项时保持连接，全部结束后自动断开。
  - 「设置 → 通知」可以分别关掉完成通知和审批通知。
- **额度用完换渠道**：Codex 因为额度用完或 429 停下时，线程里会出现一张卡片，写明哪个渠道用完、预计什么时候恢复。可以从电脑上 Codex 已配置的其他渠道里选一个模型，在原线程里接着做，也可以等恢复。不会自动切换。原渠道恢复后点「换回」。
- **分享和快捷方式**：在其他 App 里把文字、链接或最多 9 张图片分享给 MobiCodex，可以发给当前线程、开新任务或存成事项卡；内容只填进输入框，由你确认后发送。桌面长按图标有「新任务」「语音输入」和最近 3 个线程。
- 修复：打开电脑上已经不存在的线程时整页变白；Codex 记录里以错误结束的回合被当成成功。

**电脑端网关需要升级**：通知和换渠道依赖新版网关；分享和快捷方式只需要新 APK。旧网关下 App 照常可用，只是没有这两项。

## 安装

1. 用下载页的安装包覆盖安装 0.2.0（同一签名，数据保留）。
2. 电脑端：按[网关管理](../../../../plugins/mobile-codex/README.md)用本版源码构建网关（`corepack pnpm build:plugin`），沿用原配置和工作目录切换到新程序。
3. 第一次发任务时 App 会申请通知权限；拒绝后可以在「设置 → 通知」重新打开。
