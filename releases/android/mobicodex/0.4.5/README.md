# MobiCodex 0.4.5（versionCode 48）

2026-11-19 · Android 6.0+ · 包名 `com.mobilecodex.app`

## 这一版

- **反馈可以直接提交成 GitHub issue**（#52）：电脑上的网关配置了仓库以后，「反馈问题」里多一个「提交到」选项。
  - 选了仓库必须先预览。预览里的标题和正文就是要发出去的内容，已经隐藏了本机路径、用户名、电脑名、邮箱、网址、IP 地址和密钥；公开仓库会提醒“将公开发布”。
  - 确认后由网关用电脑上的 gh 提交。「我的反馈」里能点开提交好的 issue；没提交上会显示原因，网关每 10 分钟自动重试，不会重复建。
  - 选「只存到电脑」和以前一样。
- **反馈不再附带截图**：截图没法随 issue 上传，所以去掉了。从别的 App 分享图片到「反馈问题」时只保留文字，并提示图片没有附上。

0.4.4 及更早的改动见 [0.4.4 版本说明](../0.4.4/README.md)。完整列表见[更新说明](../../../../CHANGELOG.md)。

**电脑端**：要直接提交 issue，得用这一版源码重新构建网关，并在 `gateway.json` 里加上 `feedback.github`，写法见[网关管理](../../../../plugins/mobile-codex/README.md)。不加的话，反馈和以前一样只存到电脑上；旧网关配新手机也能用，只是没有「提交到」选项。

## 安装

1. 用下载页的安装包覆盖安装 0.4.4 或更早的版本（同一签名，数据保留）。
2. 要直接提交 issue：电脑上先 `gh auth login`；按[网关管理](../../../../plugins/mobile-codex/README.md)用本版源码构建网关（`corepack pnpm build:plugin`），沿用原配置和工作目录切换到新程序；在 `gateway.json` 里加 `feedback.github` 后重启网关。
3. 从 0.4.1 或更早升级并且用 Claude CLI：同样要用本版源码重新构建网关。
