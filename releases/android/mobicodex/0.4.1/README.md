# MobiCodex 0.4.1（versionCode 44）

2026-11-18 · Android 6.0+ · 包名 `com.mobilecodex.app`

## 这一版

- **会话列表更紧凑**（#39，所有 Agent 统一）：标题只占一行，第二行是灰色小字的时间（刚刚 / 23:29 / 昨天 / 11-15）和“电脑上开着”。按项目分组缩进，一屏能看到约 9 条（原来 3～4 条）。系统字号调大时，搜索按钮不再被挤成竖排。
- **设置精简**（#38）：去掉“分屏”开关，布局固定按屏幕自动排。
- **CC Desk 打开更快更稳**（电脑端网关）：
  - 网络慢时（例如 Tailscale 走中继）不再反复超时、一直显示“正在恢复连接”。
  - 读取会话时启用压缩，传输量约为原来的 1/4～1/5。
  - 离开会话后网关保留 10 分钟（原来 2 分钟）。
  - 超过 10 分钟再回来，或者断线重连时，只取离开期间新增的内容，不再整页重读。

完整列表见[更新说明](../../../../CHANGELOG.md)。

**电脑端**：CC Desk 的这几项改进需要用本版源码重新构建网关；手机端的改动只要装新 App。

## 安装

1. 用下载页的安装包覆盖安装 0.4.0（同一签名，数据保留）。
2. 用 CC Desk 的话，按[网关管理](../../../../plugins/mobile-codex/README.md)用本版源码构建网关（`corepack pnpm build:plugin`），沿用原配置和工作目录切换到新程序。
