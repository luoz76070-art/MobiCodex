# MobiCodex 0.4.0（versionCode 43）

2026-11-17 · Android 6.0+ · 包名 `com.mobilecodex.app`

## 这一版

- **新增「Claude CLI」Agent**：在网关配置里列出允许的目录（`claudeCli.directories`）后，手机上能查看这些目录里电脑上的 Claude Code 会话，继续任一会话或新建会话，实时看输出、排队或追加消息、中断；审批、提问、切换权限模式和模型都能在手机上处理。电脑上的 Claude Code 需要 ≥ 2.1.326。
- **各 Agent 平级，顶栏统一**：打开 App 先选 Agent；所有 Agent 用同一个顶栏，设置在任何页面都能打开，系统返回键逐层返回。
- **新建 Codex 会话可选项目**：从侧栏或项目里新建时，会话建在所选项目里，不再落到网关的默认目录（#31）。
- **常用指令**：所有 Agent 输入框上方一排可横滑的指令，点一下填进草稿；在设置里增删和排序。
- **App 内反馈**：设置里的「反馈问题」、长按消息的「反馈这条」、分享面板里的「反馈问题」，反馈存到电脑网关的收件箱。
- **电脑离线提醒和保持唤醒**：手机有任务在跑、电脑网关连续两分钟连不上时提醒一次；电脑上有任务运行时网关阻止空闲睡眠。
- 修复：额度用完后在手机上换模型不生效（#30）；CC Desk 切屏回来恢复慢（#20）；点 CC Desk 的通知会打开 Codex；长按菜单一抬手就关。

完整列表见[更新说明](../../../../CHANGELOG.md)。

**电脑端**：除常用指令外，这些功能都需要用本版源码重新构建网关。

## 安装

1. 用下载页的安装包覆盖安装 0.3.1（同一签名，数据保留）。
2. 按[网关管理](../../../../plugins/mobile-codex/README.md)用本版源码构建网关（`corepack pnpm build:plugin`），沿用原配置和工作目录切换到新程序。
3. 要用 Claude CLI：在网关配置里加 `"claudeCli": { "directories": ["<允许的目录>"] }`，重启网关。
